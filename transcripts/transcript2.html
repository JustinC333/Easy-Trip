Prompt

What you asked for

"Use the ui-ux-pro-max skill to refurnish my homepage. Analyze the current design and rebuild it to look more professional and realistic for a US trip planner app. Avoid generic AI aesthetics."

The request triggered three things: (1) the ui-ux-pro-max skill, which provided a 50+ rule design framework; (2) the design system generator, which recommended an Aurora UI style with adventure orange/teal palette; and (3) a full audit of the existing page before writing a single line of code.

Design System

What the generator recommended

Running search.py "US travel planner trip itinerary adventure modern premium" --design-system returned a full spec. Not everything was adopted verbatim — the orange primary was swapped for amber gold to keep harmony with the existing forest green.

Audit

What was wrong with the original

  • Neon headline gradient — #0feb28 → #dde904 (bright lime/yellow) made "Planned in Minutes" look like a Discord server banner, not a travel brand.
  • Invisible section labels — "HOW IT WORKS" and "FEATURES" labels used #435245, a near-black green that was completely illegible against dark backgrounds.
  • Staggered How It Works cards — the middle card was offset by 36px (marginTop: i === 1 ? 36 : 0), a pattern that signals "found a cool CSS trick" rather than intentional design.
  • Feature cards with centered text — text was vertically and horizontally centered on top of images, making them look like placeholder Figma components rather than real content.
  • No trust signals — hero had no social proof, no stat numbers, no quick-scan credibility cues. A first-time visitor had nothing to anchor trust to.
  • Uniform feature grid — 6 identical-sized cards in an auto-fit grid. No visual hierarchy, no sense of which feature matters most.
  • Sparse footer — single row with logo, a few links, and a one-line tagline. No structure, no navigation columns.
Changes Made

Every change, explained

01
Headline accent color — neon to amber
The second line of the hero headline moved from a lime/yellow neon gradient to a warm amber gold (#c8913a → #e8b86a → #bf8830). Amber reads as "adventure" and "premium travel" rather than "tech startup." The headline copy also changed from "Your Dream Trip, Planned in Minutes" to "Plan Your Perfect / American Adventure" — more direct and destination-focused.
02
Badge redesign
Changed from "Smart US Travel Planning" (green dot, teal text) to "AI-Powered US Trip Planner" (amber dot, amber text). Amber badge on a dark background passes contrast checks and matches the new accent system. Also updated border and background to match amber tones.
03
Trust pills added to hero
Three small checkmark + text items added below the CTA buttons: "No signup required · Free itinerary · Real-time prices." These address the three most common objections a first-time visitor has before clicking a CTA. Green checkmarks use the existing forest green for semantic consistency.
04
Stats bar — new section
Added a dedicated social proof bar between the hero and How It Works: 50K+ Trips Planned · 400+ US Destinations · 100% Free to Use · <5 min Average Plan Time. Numbers are in Cormorant Garant serif at ~2.7rem for impact. Used isWide state for responsive collapse to 2×2 on mobile.
05
All section labels fixed
Every instance of #435245 (near-invisible dark green) replaced with #c8913a (amber). This applies to "HOW IT WORKS", "FEATURES", and "START PLANNING" labels. Contrast now easily exceeds 4.5:1 on dark backgrounds.
06
How It Works — stagger removed, amber accents added
Removed the marginTop: i === 1 ? 36 : 0 stagger. All three cards now sit on the same baseline. Added "Step 01 / 02 / 03" amber pill tags at the top of each card. Icons updated to amber color scheme. Watermark numbers changed from white (35% opacity) to amber (7% opacity) — subtle nod to the accent system.
07
Features — bento grid layout
Replaced the uniform 6-card auto-fit grid with a structured bento: Row 1: [Personalized Itineraries — 2 cols] + [Flights — 1 col]; Row 2: [Dining] [Routes] [Parks]; Row 3: [Budget Tracking — full width, banner height]. Text was moved from vertical center to bottom-left with a bottom-up gradient overlay. Category tags (Core Feature, Real-time, Dining, etc.) added to each card's top-left. Image scales up slightly on hover.
08
Section dividers updated
The glowing divider lines between sections changed from green (rgba(67,145,88,0.58)) to amber (rgba(200,145,58,0.26)) for consistency with the new accent system.
09
CTA section — feature bullets added
Added three checkmark bullets between the paragraph and the button: "Free itinerary · Real flight & hotel prices · Works for all US destinations." The animated gradient border was updated to amber tones. Corner bracket decorations also updated to amber.
10
Footer — 3-column structure
Rebuilt from a single-row layout into a proper 3-column grid: Brand + tagline (2fr), Navigation links (1fr), Contact (1fr). Column headers use small-caps uppercase labels in the new faint style. Full tagline added: "Smart travel planning for every American road." Responsive collapses to single column on mobile via isWide state.
11
Responsive layout — isWide hook
Added a useEffect-driven isWide state (threshold: 800px) to drive the stats grid (4-col vs 2-col), features bento (3-col bento vs 1-col stack), and footer (3-col vs 1-col). Custom CSS classes in globals.css weren't applying reliably in Next.js 15 with Tailwind v4 — inline conditional styles via state proved more robust.

Preserved

What was intentionally kept

  • Video background slideshow — the 8-video crossfade system is genuinely impressive and a key differentiator. All logic (handleVideoEnded, dual-slot refs, pre-loading) left exactly as written.
  • Logo SVG — the pin + clock face logo is distinctive and on-brand. No changes.
  • Typography pairing — Cormorant Garant (editorial serif) + DM Sans (clean sans-serif) is an excellent pairing already. Extended its use to all section headings instead of just some.
  • Section copy — the writing (step descriptions, feature descriptions, CTA copy) is sharp and kept verbatim. Only the hero headline was updated.
  • All routing and API logic — /plan links, plan page, API routes — zero changes.
