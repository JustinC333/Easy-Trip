Part 1 — New API Route
NEW Master Orchestration Endpoint
app/api/plan/route.ts
A single POST /api/plan endpoint that drives the entire trip generation pipeline in sequence. Every step is console-logged for debugging.
Step 1 — Authenticate
Calls supabase.auth.getUser(). Returns 401 if no session.
Step 2 — Validate input
Requires at least one destination with state + city, plus start/end dates. Returns 400 on failure.
Step 3 — Cost guard
Calls checkAndReserve(userId, 3000). Returns 429 if the user has hit their monthly token ceiling.
Step 4 — Enrich
Calls POST /api/enrich with the first destination. If it fails for any reason, enrichment is set to null and generation continues — enrichment is never a blocker.
Step 5 — Generate
Calls POST /api/generate with the full form body + enrichedContext. Returns 500 if Claude fails.
Step 6 — Record usage
Calls recordUsage(userId, tokensUsed) with the actual token count returned by the generate step.
Step 7 — Save trip
Builds a human-readable destination string (City, State → City, State), then calls saveTrip() which inserts to Supabase and returns a tripId.
Step 8 — Done
Returns { tripId } with status 200.
